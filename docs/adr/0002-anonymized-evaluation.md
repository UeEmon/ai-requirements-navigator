# ADR 0002: 複数AIの結果は匿名化して別のAIが評価する

- 状態: 決定
- 日付: 2026-10-02

## 決定

1. 生成AIの案を「案A／案B…」に置き換え、提示順をランダムにしてから評価AIに渡す
2. 評価AIは基準ごとの点数・長所短所・推奨・統合案を返す。**合計点はAIの申告ではなくアプリ側で重みから計算する**
3. 評価AIが生成AIと同じ場合は警告する（自己贔屓の偏り）
4. 決定前は、利用者にもどの案がどのAIのものかを見せない。決定後に対応を表示し、決定記録に残す
5. 一部の生成AIが失敗・時間切れでも、取得できた案で評価を続ける。全て失敗した場合のみエラー
6. 最終判断は常に利用者が行い、項目単位で選んで採用できる

## 理由

- ベンダー名による先入観（利用者・評価AIの双方）を避ける
- 採点の計算ミスや改ざんをアプリ側で防ぐ
- 1社の障害で作業が止まらないようにする
